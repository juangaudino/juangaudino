## About me

I'm a product-minded developer building web applications with **React, TypeScript, Supabase, PostgreSQL, APIs, and AI-assisted development tools**.

Before moving into software product development, I spent 15+ years in advertising and OOH/DOOH media across strategy, analytics, operations, client management, and team leadership. That background shapes how I build today: I start with the **problem, workflow, and user**, not just the requested feature.

I'm especially interested in turning processes that live in spreadsheets, forms, messages, or repetitive manual work into useful software.
